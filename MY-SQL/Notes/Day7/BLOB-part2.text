Answer Key

1. What is the primary difference between the storage behavior of Binary and Varbinary data types? The Binary data type utilizes a fixed storage size, whereas the Varbinary type is not fixed. Varbinary only uses the amount of bytes required for the specific characters being stored, up to its maximum range.
2. What is the storage range of the Binary data type, and what is its most common application? The Binary data type has a storage range of 255 and uses 1 byte. It is commonly used for fixed-range data, such as converting password text into a binary format.
3. How does the Binary data type handle a situation where the input text, such as "hi," is smaller than the allocated size? Because Binary is a fixed-size format, it fills any unused space with null values to meet the required range. For example, storing "hi" would result in the two character bytes followed by a series of null placeholders.
4. What is the storage capacity of a TinyBlob, and what specific types of files is it designed to store? A TinyBlob has a storage capacity of 255 bytes. This data type is specifically used for storing very small binary items, such as tiny icons.
5. Which data type is most appropriate for storing standard small images, and what is its maximum storage capacity? The standard Blob data type is used for storing small images. It provides a storage capacity of up to 65,535 bytes.
6. In what scenarios would a MediumBlob be utilized instead of a standard Blob? A MediumBlob is utilized when the files, such as larger images or documents, exceed the 65,535-byte limit of a standard Blob. It offers a significantly larger storage capacity of 16 MB.
7. What is the maximum storage capacity of a LongBlob, and what types of content are typically stored in this format? A LongBlob can store up to 4 GB of data. This capacity is intended for very large files, including videos and high-volume documents.
8. What are the initial steps required to prepare an image for upload into a MySQL database? The image must first be moved to the specific MySQL Uploads directory (typically C:\ProgramData\MySQL\MySQL Server 8.0\Uploads). Afterward, the user must access the image's properties and security settings to copy the exact file URL or location.
9. When pasting a file URL or location into MySQL, what specific formatting changes must be made to the file path? The user must ensure that all slashes in the file path are in the backward direction. Additionally, the "C:/" portion of the path must be removed and rewritten manually before running the command.
10. Once the insert command has been executed, how can a user verify that the image is correctly stored in the database? To verify the storage, the user should locate the BLOB entry within the database. By right-clicking on the BLOB, they can view the image to ensure the upload was successful.

Glossary of Key Terms

Term	Definition
Binary	A fixed-size data type with a range of 255; commonly used for passwords and text conversion where data is padded with nulls if it does not fill the allocated size.
Varbinary	A variable-sized binary data type with a range of 65,535; it only consumes the number of bytes required by the stored characters.
BLOB	Acronym for "Binary Large Object," a category of data types used to store large amounts of binary data like images or documents.
TinyBlob	The smallest BLOB type, limited to 255 bytes; primarily used for storing tiny icons.
MediumBlob	A binary storage format with a capacity of 16 MB, suitable for storing documents and medium-sized images.
LongBlob	The largest binary storage format, capable of holding up to 4 GB; used for videos and large-scale documents.
Null Padding	The process used by the fixed-size Binary type where empty space at the end of a data entry is filled with null values.
Path Direction	The specific requirement in MySQL commands that file path slashes must be oriented in the backward direction.
MySQL Uploads Directory	The specific system folder (located in ProgramData) where files must be placed before they can be imported into the database via command.
